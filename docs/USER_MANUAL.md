# 🛠️ Workshop Maker ("Workshopizer") — User Manual & Architecture Guide

> **Welcome to the Workshop Maker!**  
> A lightweight, zero-dependency, high-elegance authoring and visualization engine designed to transform single-file Markdown documents into interactive, Google Codelabs-style multi-step workshops with live hot-reloading, Glassmorphism UI, and static multi-doc compilation.
>
> *Author Note:* Designed with love for Riccardo & Emiliano's workshops. Built to be easily extracted into a standalone gem or standalone repository in the future! 🚀

---

## 🧭 1. Overview & Vision

Writing technical workshops is often painful when tied to heavy frameworks or proprietary platforms. The **Workshop Maker** follows the **"Markdown-as-Code"** philosophy:
1. **Single Source of Truth:** Write your entire workshop in standard GitHub Flavored Markdown (`CODELAB.md` or `UNTOUCHABLE-CONSTITUTION.md`).
2. **Deterministic Step Splitting:** Every Level 2 header (`## Step Title`) or Level 3 header (`### Step Title`) automatically becomes a discrete, trackable chapter.
3. **Dual Visualizers:**
   - **Interactive Live Server (`server.rb`):** A self-healing Sinatra server with client-side hash navigation, code syntax highlighting, callout boxes, and multi-doc switching.
   - **Static Site Generator (`build_ghpages.rb`):** Compiles clean, zero-server static HTML files for hosting on GitHub Pages, Google Cloud Storage, or Firebase Hosting.
   - **Modular SPA Engine (`split_codelab.rb`):** Splits the master document into atomic JSON/Markdown bundles (`render-app2/pages/`) for modern frontend SPAs.

## 🏗️ 2. Core Architecture

```
workshop/
├── CODELAB.md                      # 📖 Master workshop narrative
├── UNTOUCHABLE-CONSTITUTION.md     # 📜 Master architectural contract & rules
├── SKELETON.md                     # 🦴 High-level steps summary
│
├── server.rb                       # 🚀 Live Sinatra visualization server (with doc switcher)
├── split_codelab.rb                # ✂️ Chops markdown into render-app2/pages/*.md
├── build_ghpages.rb                # 🏗️ Compiles multi-doc static HTML to build/
│
├── assets/                         # 🖼️ Workshop images & media
│   └── images/
│
├── build/                          # 📦 Static HTML output (ready for GH Pages/GCS)
│   ├── index.html                  # Codelab viewer
│   ├── constitution.html           # Constitution viewer
│   ├── skeleton.html               # Skeleton viewer
│   └── assets/                     # Copied media assets
│
└── render-app2/                    # 💎 Blue/Black Glassmorphism SPA visualizer
    ├── index.html
    ├── pages/                      # Auto-generated by split_codelab.rb
    │   ├── 01-introduction.md
    │   ├── 02-setup-and-prerequisites.md
    │   └── pages.json
    └── css/ & js/
```

## 🚀 3. How to Use the Workshop Maker

### 🧑‍💻 Running the Live Visualizer

You can launch the visualizer directly with `just` or standard Ruby:

```bash
# Launch the Codelab live visualizer on port 8080 (default)
just workshop-dev

# Launch on a custom port (e.g. 4567)
just workshop-dev port=4567

# Launch directly focused on the Untouchable Constitution
just workshop-constitution
```

Or using Ruby directly from the `workshop/` folder:
```bash
cd workshop
./server.rb                       # Serves CODELAB.md by default
./server.rb UNTOUCHABLE-CONSTITUTION.md   # Serves any specific markdown file
./server.rb -p 3000 SKELETON.md   # Custom port
```

### 🔀 Multi-Document Switching

The live server automatically provides tabbed navigation in the sidebar header:
- `http://localhost:8080/` or `/codelab` $\rightarrow$ [`CODELAB.md`](file:///usr/local/google/home/ricc/git/rails8-app-on-gcp/workshop/CODELAB.md)
- `http://localhost:8080/constitution` $\rightarrow$ [`UNTOUCHABLE-CONSTITUTION.md`](file:///usr/local/google/home/ricc/git/rails8-app-on-gcp/workshop/UNTOUCHABLE-CONSTITUTION.md)
- `http://localhost:8080/skeleton` $\rightarrow$ [`SKELETON.md`](file:///usr/local/google/home/ricc/git/rails8-app-on-gcp/workshop/SKELETON.md)
- `http://localhost:8080/?file=path/to/any.md` $\rightarrow$ Any arbitrary markdown file!

### 🏗️ Building Static HTML Distribution

To generate static HTML files for deployment:

```bash
just build-ghpages
```

This will:
1. Run `split_codelab.rb` to update `render-app2/pages/` and `pages.json`.
2. Run `build_ghpages.rb` to generate `build/index.html`, `build/constitution.html`, and `build/skeleton.html`.
3. Copy all media assets from `assets/` to `build/assets/`.

## ✍️ 4. Authoring Guidelines for Codelabs

To author a codelab that renders beautifully:

### 1. Frontmatter Metadata (Optional)
Add YAML frontmatter at the top of your markdown document:
```yaml
---
title: Rails 8 on Google Cloud: From Zero to AI
author: Riccardo & Emiliano
duration: 90
category: cloud, ruby, rails, gemini
---
```

### 2. Main Title (`# Header 1`)
The H1 title is extracted as the workshop title and displayed in the sidebar:
```markdown
# Rails 8 on Google Cloud: From Zero to AI
```

### 3. Step Splitting (`## Header 2`)
Every `##` becomes a new step in the navigation sidebar:
```markdown
## Step 1: The Local Baseline
Here is how to set up the local Rails app...

## Step 2: Cloud Storage
Now let's switch ActiveStorage to Google Cloud Storage...
```

### 4. Interactive Callout Boxes
Standard markdown blockquotes are automatically converted into Google Codelab styled info-boxes based on keywords or emojis:

```markdown
> 💡 **Tip:** Use `iam: true` in storage.yml for private blob signing.   <!-- Green Positive Box -->
> ⚠️ **Warning:** Never expose port 5432 to 0.0.0.0/0 in production!     <!-- Yellow Warning Box -->
> 🛑 **Caution:** Do not commit master.key to git!                      <!-- Red Danger Box -->
```

GitHub Alert syntax (`[!NOTE]`, `[!TIP]`, `[!WARNING]`, `[!IMPORTANT]`, `[!CAUTION]`) is also fully supported!

## 📦 5. Extracting into a Standalone Repository / Gem

When you are ready to decouple the **Workshop Maker** into its own independent project (e.g. `github.com/palladius/workshopizer` or `gem install workshopizer`):

### What to Extract:
1. **The CLI / Server Engine:** `server.rb` $\rightarrow$ Can be packaged as an executable CLI `bin/workshopizer`.
2. **The Build Engine:** `build_ghpages.rb` & `split_codelab.rb` $\rightarrow$ Subcommands `workshopizer build` and `workshopizer split`.
3. **The Static Assets & Templates:** The inline Sinatra template (`@@index`) and `render-app2/` Glassmorphism SPA styles extracted into `templates/` or `public/`.

### Proposed CLI Interface for the Standalone Gem:
```bash
# Preview any markdown codelab in real-time
workshopizer serve ./my-codelab.md --port 8080

# Build static multi-page HTML site
workshopizer build ./my-codelab.md --output ./dist/

# Initialize a new workshop boilerplate
workshopizer init my-new-workshop
```
