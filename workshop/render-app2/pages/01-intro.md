# 1. Introduction

Welcome to the **Rails 8 on GCP** Workshop!

In this workshop, you will learn how to build a production-ready Ruby on Rails 8 application and deploy it natively on Google Cloud.

## What we will cover:
- Running Rails 8 locally with Docker-compose
- Integrating Google Cloud Storage for ActiveStorage
- Setting up Cloud SQL for PostgreSQL
- Deploying to Cloud Run
- Setting up CI/CD pipelines
