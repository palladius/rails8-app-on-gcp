# 📅 Workshop Events Directory

This directory tracks editions and deliveries of the **Rails 8 on Google Cloud** workshop.

## Directory Structure

Each event is structured as `workshop/events/YYYYMMDD-EVENT_NAME/`:
- `README.md`: Event summary, date, location, attendees, co-speakers, slides link, and retrospective notes.
- `slides/`: Event-specific slides (or symlink/copy of `slides/` tailored for the conference).
- `assets/`: Event-specific photos, branding, or custom artifacts.
