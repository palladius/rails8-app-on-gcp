# Workshop Skeleton Spec

## Overview
Develop branches `workshop_1_local_baseline` through `workshop_6_ai_features` based on the finalized `SKELETON.md` plan. These branches will be used in the rails8-app-on-gcp workshop.

## Functional Requirements
1. Create branch `workshop_1_local_baseline` representing the base setup.
2. Create branch `workshop_2_cloud_storage` setting up GCS for ActiveStorage.
3. Create branch `workshop_3_cloud_sql` setting up Cloud SQL connection.
4. Create branch `workshop_4_cloud_run_classic` setting up Cloud Run deployment.
5. Create branch `workshop_5_cloud_build_cicd` adding CI/CD.
6. Create branch `workshop_6_ai_features` for AI features.

## Non-Functional Requirements
- Ensure branches stem logically, possibly as a linear progression or all from a base state, depending on the SKELETON.md intent.

## Acceptance Criteria
- 6 branches exist remotely and locally corresponding to the names above.
