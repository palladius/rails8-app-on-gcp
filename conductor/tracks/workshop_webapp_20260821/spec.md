# Workshop Web App Specification

## Overview
Create a standalone, 7-10 page scrollable workshop web application hosted on GitHub Pages. The app will dynamically fetch and render content from separate Markdown files to keep authoring simple.

## Functional Requirements
1. Horizontal scrolling navigation between 7-10 pages.
2. Fetch and render Markdown content dynamically.
3. Vanilla HTML/CSS/JS architecture (no build step).
4. Compatible with GitHub Pages.
5. Worktree isolation for development.

## Out of Scope
- Backend functionality or databases.
- Build tools (Webpack, Vite, etc.).
