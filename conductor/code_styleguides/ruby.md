# Ruby & Rails Code Style Guide

As per the project requirements, we defer to the **Carlessian ruby-coding skill** for our Ruby and Ruby on Rails conventions. 

## Key Principles:
1. **Friendly & Instructional:** Add comments above complex Rails configurations and GCP infrastructure code to explain the "why" to workshop attendees.
2. **Readability First:** Favor explicit code over clever Ruby tricks. Attendees must be able to parse logic instantly.
3. **Fail Fast:** Missing environment variables must crash the application immediately to aid debugging.
